Haiti Workshop and Coordination Work Trip
A Global Food Institute field report on the Crisis-Resilient School Meals (CRSM) pilot, July 2026.

TO VIEW
Unzip the folder, then double-click index.html. It opens in any web browser.
Keep index.html and the photos folder together.

TO PUT IT ONLINE
Upload the whole folder (index.html + photos) to any web host, for example:
  - Netlify Drop (free): drag the folder onto https://app.netlify.com/drop
  - GitHub Pages (free): upload the files to a repository and turn on Pages in Settings
  - The GW / GFI website: hand the folder to the web team

GOOD TO KNOW
  - All photos are inside the photos folder; nothing depends on the original StoryMap.
  - The page needs an internet connection for its fonts, the interactive map, and the
    driving route. Without one, the text and photos still show, but the map stays blank.
  - All text lives in index.html. The trip stops (titles, captions, coordinates, photos)
    are in the STOPS list near the bottom of that file.
